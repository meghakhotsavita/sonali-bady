SONALI'S BIRTHDAY WEBSITE

FOLDER SETUP
Keep index.html, photos, and videos together in the same folder:
sonali_birthday_fixed/
  index.html
  photos/photo1.jpg ... photos/photo8.jpg
  videos/video1.mp4 ... videos/video4.mp4

IMPORTANT
1. Copy your eight real photos into the photos folder and name them exactly photo1.jpg through photo8.jpg.
2. Copy your four videos into the videos folder and name them exactly video1.mp4 through video4.mp4.
3. Keep the same file extensions. If a photo is .png, either convert it to .jpg or change the matching filename in index.html.
4. Open index.html in Chrome or Edge. If already open, press Ctrl+F5 to refresh.
5. If the page shows "Photo not found", check that index.html and the photos folder are next to each other and the filename is exact.

Personal photos/videos are not included in this ZIP; they need to be copied in from your computer.
